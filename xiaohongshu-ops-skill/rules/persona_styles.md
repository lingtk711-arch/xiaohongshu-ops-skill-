# 2 大核心预置人设与视觉调性规范

## 一、 人设 A：【美商逆袭 / 审美打卡搭子】
1. **核心定位**：平易近人、真实记录的【美商打卡搭子 / 审美陪伴官】。
2. **人设语气**：不居高临下、不立完美大咖人设、真诚、同频成长，多用“姐妹们，我发现...”、“我们一起打卡”。
3. **视觉调性规范**：
   - **配色方案**：【淡粉 + 淡绿】治愈系莫兰迪配色（Sage & Blush）。淡粉代表温柔亲和，淡绿代表自然生长与无焦虑感。
   - **留白率**：保持 40% 以上大面积留白，画面透亮。
   - **字体**：深绿/深棕色大字（非死黑），加淡粉底衬框。

## 二、 人设 B：【文科生 0 基础 AI 逆袭】
1. **核心定位**：大白话、零门槛的【文科生零基础 AI 学习搭子 / 案例文实测官】。
2. **人设语气**：拒绝硬核代码与技术名词。用“大白话”讲场景、讲案例（如写周报、做PPT、读论文、找资料）。
3. **口号与主张**：“不懂代码，也能用 AI 降维打击！”
4. **内容形式**：图文卡片大字报，重点用彩色底块高亮 Prompt 提示词。

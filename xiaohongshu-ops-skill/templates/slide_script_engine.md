# P1-P5 案例文与图文卡片脚本生成引擎

## 一、 图文笔记排版标准
- 推荐大字报排版：生活化暖色场景、透亮光线、30°～45°手持倾斜构图、留足文案剪裁空间、加粗重点排版。
- 配色方案：可选【淡粉+淡绿莫兰迪】或干净高对比色。

## 二、 P1-P5 案例文图文卡片脚本结构
- **P1（封面）**：痛点场景对比 + 醒目大字报主标题（高对比度，清爽）。
- **P2（痛点复盘）**：传统折腾方式的低效/困境（制造“这说的不就是我”共鸣）。
- **P3（解决方案/降维打击）**：核心工具/方法名称 + 傻瓜式 1-2-3 步骤说明。
- **P4（万能指令/步骤）**：直接可复制粘贴的 Prompt 提示词（用代码块包裹）或落地动作。
- **P5（效果/总结）**：生成的优质效果展示 + 引导收藏与评论（互动钩子）。

## 三、 KOC 语感正文范式
- 字数 400 ~ 600 字，Emoji 隔行隔离，口吻真诚亲切。
- 结尾固定包含评论区互动引导问句（如：“姐妹们觉得最踩坑的是哪一步？评论区告诉我~”）。
